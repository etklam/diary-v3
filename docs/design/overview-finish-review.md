# Overview finish review

The ticket30 Overview candidate is in progress. The signed-in home route now composes the existing bounded projections for attention, review queue, recent diary decisions, trade plans, portfolio valuation and the stock watchlist. It does not introduce a second ledger, calculation engine, authorization path or unbounded list: each request uses the existing endpoint contract and the view caps the rendered rows for a calm first screen.

The page follows the approved composition in `docs/design/overview-implementation-brief.md`: follow-up actions and review groups lead the main column, recent decisions and trade plans remain below them, and portfolio context plus tracked companies sit in the supporting column on desktop. The supporting column returns below the main content on narrow screens. Every section has independent loading and retry state, so a failed attention request leaves recent decisions and research context readable.

The current implementation also keeps account-local date semantics explicit. The account timezone is loaded from `/api/auth/me`; while it is loading or unavailable the header reports that state and due/update instants show `Unknown` instead of silently presenting UTC as the account's local time. Review outcomes are translated into user-facing labels rather than exposing enum keys.

Static checks for the candidate pass targeted ESLint and the repository typecheck is green after the concurrent market-rotation test correction; no Overview or home-route error remains. The focused browser file is `tests/e2e/overview.spec.ts`, covering synthetic Diary, Thesis, Trade Plan, holding/risk attention, watchlist research, empty state, independent attention failure/retry, navigation, three locales, dark mobile evidence and page-overflow checks.
